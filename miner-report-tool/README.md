# ابزار ساخت گزارش تخلیه اطلاعاتی ماینر

از عکس‌های هر دستگاه (عکس لیبل + اسکرین‌شات صفحه Miner Log) اطلاعات زیر را خودکار استخراج می‌کند
و گزارش نهایی را با همان سربرگ و ساختار گزارش نمونه به Word یا PDF می‌سازد:

| داده | منبع استخراج |
| --- | --- |
| مدل دستگاه (مثل `M30S+`) | فیلد `P/N` روی لیبل |
| هش‌ریت (مثل `102T`) | فیلد `TYPE` روی لیبل |
| شماره سریال | **کد QR** لیبل (دقیق) و در صورت نبود QR از OCR متن لیبل |
| تاریخ آخرین یوزر ثبت‌شده | آخرین سطر `user from ... to ...` در تب `Pools Change log` |
| مدت کارکرد | از تاریخ آخرین یوزر تا **تاریخ کشف** که دستی وارد می‌کنید (شمارش شامل روز اول و روز کشف، مطابق گزارش نمونه) |

تاریخ استارت هم به‌صورت میلادی و هم شمسی در گزارش درج می‌شود: `11 سپتامبر 2025  ( 20/06/1404 )`.

## نصب

```bash
pip install -r requirements.txt
```

پیش‌نیازهای خارج از پایتون:

- **Tesseract OCR** (برای خواندن متن لیبل و لاگ)
  - ویندوز: نصب از https://github.com/UB-Mannheim/tesseract/wiki و افزودن مسیر نصب به `PATH`
  - لینوکس: `sudo apt install tesseract-ocr`
- **LibreOffice** فقط اگر خروجی PDF می‌خواهید (`soffice` باید در `PATH` باشد).

## قالب گزارش (سربرگ)

فایل وورد گزارش نمونه (همان فایلی که سربرگ، مهر و امضا در آن است) را با نام `template.docx`
کنار همین پوشه بگذارید. این فایل به‌دلیل داشتن مهر و امضا در مخزن قرار نگرفته است.
ابزار سربرگ، فونت‌ها، کادرها و رنگ عدد «مدت کارکرد» را از همین قالب برمی‌دارد.

## روش ۱: رابط وب محلی (ساده‌ترین)

```bash
python -m minerreport.webapp
```

سپس در مرورگر `http://127.0.0.1:8765` را باز کنید:
اطلاعات سربرگ و تاریخ کشف را وارد کنید → عکس‌ها را انتخاب کنید → «اسکن عکس‌ها» →
مقادیر استخراج‌شده را در جدول بازبینی/اصلاح کنید → «دریافت وورد» یا «دریافت PDF».

## روش ۲: خط فرمان

اسکن و ساخت گزارش در یک مرحله:

```bash
python -m minerreport.cli run \
  --images ./photos \
  --discovery 1404/08/03 \
  --province قم \
  --case-unit "11 دستگاهی رستمی-خانی – شرکت توزیع قم" \
  --address "اداره أموال تملیکی" \
  --report-number ZTG-1405-0023 \
  --approver "مهندس نجفی" \
  --template template.docx \
  --output report.docx --pdf
```

اگر می‌خواهید قبل از ساخت گزارش، داده‌های استخراج‌شده را بازبینی کنید:

```bash
python -m minerreport.cli scan --images ./photos --discovery 1404/08/03   # devices.json ساخته می‌شود
# devices.json را اصلاح کنید (سریال، مدل، تاریخ استارت، آمپر و ...)
python -m minerreport.cli build --data devices.json --template template.docx --output report.docx --pdf --csv summary.csv
```

## تفکیک عکس‌های هر دستگاه

- **مطمئن‌ترین راه:** نام فایل را با شماره دستگاه شروع کنید: `1-label.jpg` و `1-log.png`، `2-label.jpg` …
- یا هر دستگاه را در یک پوشه بگذارید: `photos/device_01/…`
- در غیر این صورت عکس‌ها به ترتیب زمان عکس‌برداری (EXIF) دو‌به‌دو (لیبل + لاگ) گروه می‌شوند.
- خواندن شماره دست‌نویس قرمز روی عکس با `--read-marker` ممکن است، ولی دست‌خط اغلب اشتباه خوانده
  می‌شود؛ به‌صورت پیش‌فرض خاموش است.

## بازبینی انسانی

سریالی که از QR خوانده شود دقیق است؛ اگر QR خوانده نشود سریال از OCR می‌آید و در ستون «وضعیت»
(و در `devices.json` در فیلد `warnings`) هشدار «نیاز به بازبینی» ثبت می‌شود. قبل از تحویل گزارش،
سریال‌های هشدار‌دار را با عکس مقایسه کنید.
